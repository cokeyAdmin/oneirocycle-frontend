# 前后端契约需求清单

状态：待前后端共同确认，不是服务端已批准 OpenAPI；本文件不定义 HTTP 路径，不生成臆测接口。

## 权威来源与发布

- [ ] 确认权威 OpenAPI 文件的仓库、路径、版本及维护责任人。
- [ ] 确认前端拉取固定版本/commit/hash 的流程；生成类型只读，不手改。
- [ ] CI 校验 schema、破坏性变更、生成类型漂移及示例；契约通过后再实现 transport。
- [ ] 独立仓库间的变更申请、兼容窗口和废弃策略。

## 全局协议

- [ ] 服务地址/版本、operationId、JSON 命名、日期/时区、空值、ID 格式。
- [ ] 结构化错误码、用户安全消息、requestId、字段错误、限流和 Retry-After。
- [ ] Cookie/BFF 或其他认证；CSRF、CORS、会话过期、刷新/注销及权限错误。
- [ ] 幂等 key 的归属、有效期、重复提交结果及超时查询方式。
- [ ] 分页、排序、过滤和资源访问权限；服务端不信任客户端身份或费用确认。

## 账户、项目与文档

- [ ] 当前会话、用户和项目权限结构。
- [ ] 项目读写/列表；项目文档 schemaVersion、revision、条件写入、冲突响应及历史恢复。
- [ ] 文档迁移责任、并发编辑策略、离线草稿恢复及资产失效处理。

## 资产

- [ ] 元数据、所有权、媒体类型、尺寸/时长及安全访问 URL 的过期刷新。
- [ ] 上传授权、大小/类型限制、分片/校验、上传完成确认、删除及引用约束。

## 图像与视频生成

- [ ] 文生图、图生图、文生视频、图生视频各自的输入/参数/引用资产结构。
- [ ] 模型能力目录、参数范围、计费确认、额度与审批规则。
- [ ] 提交结果必须返回持久 taskId，状态查询、列表与取消语义。
- [ ] 任务状态枚举、合法转换、终态、失败/部分失败、可重试性、结果资产。
- [ ] 进度未知与真实百分比的区分；不得将已提交当成功。
- [ ] SSE/WebSocket/轮询方案、鉴权、事件 schema、单调序号、游标、心跳与补偿查询。
- [ ] 重连时先查询权威快照，再恢复订阅；处理乱序/重复/游标过期与取消竞态。
- [ ] 超时不能证明提交失败，按幂等 key 查询，不自动重复扣费。

## 画布、3D 与 Agent

- [ ] 节点、边、坐标/单位、相机/场景可序列化结构及引用完整性。
- [ ] Agent 命令白名单、共享 commandId、权限、费用和破坏性确认。
- [ ] Agent 决策/checkpoint 与生成任务生命周期分离，以持久 ID 关联。
- [ ] 确认 OpenAPI 不覆盖的实时事件协议采用哪种权威规范，避免两份冲突定义。

## 当前实现边界

无服务端契约文件已提供，未连接任何真实 API。后续可使用明确标注的开发 mock，但不能生成虚假的成功或资产；真实模型密钥只允许服务端保存。
