# 环梦篇章 AIGC 前端需求

来源：Phase 1 为用户 2026-11-13 明确规格；Phase 2 为 Linear CAR-5 及其关联 Stitch 桌面/移动设计。

## Phase 1 — 前端基础工程

- [x] **ENG-01**：在现有前端独立仓库初始化，不覆盖 LICENSE 或修改后端。
- [x] **ENG-02**：安装兼容稳定依赖，提交锁文件；strict TypeScript、Next.js App Router、Tailwind 可构建。
- [x] **MOD-01**：建立账户、项目、资产、图像生成、视频生成、画布、3D、Agent 边界；不堆积空文件。
- [x] **LOAD-01**：画布及 3D 客户端按需加载；验证普通入口不加载引擎。
- [x] **STATE-01**：区分 Query 服务端缓存、Zustand 临时状态、可序列化项目文档；记录撤销/恢复/版本边界。
- [x] **CMD-01**：手动和 Agent 共用类型化创建节点、调整相机、提交任务命令；权限和幂等边界可测试。
- [x] **API-01**：统一客户端、结构化错误、认证接口；真实传输待 OpenAPI，不猜测 URL。
- [x] **JOB-01**：定义并核验任务查询、失败、取消、进度订阅、断线重查和终态停止规则；不伪造生成成功。
- [x] **CONTRACT-01**：交付前后端 OpenAPI 协商清单及契约接入步骤。
- [x] **QA-01**：环境变量示例、启动/格式化/lint/typecheck 配置；必要领域测试、production build、实际 HTTP 启动核验。
- [x] **FLOW-01**：初始化任务关联 Linear，需求/计划/验收文档可追踪；无未授权推送、部署或页面实现。

## Phase 2 — 首页（CAR-5）

- [x] **HOME-01**：按 CAR-5 指定 Stitch 桌面 Screen/HTML 实现桌面首页的导航、创作区域、功能滚动区、灵感作品流及液态玻璃视觉。
- [x] **HOME-02**：按 CAR-5 指定的独立移动 Screen/HTML 实现移动首页和悬浮输入框展开/收起；不可把桌面定宽布局简单缩小。
- [x] **HOME-03**：交互、切换、滚动和按钮可操作；未连接的后端/生成/导航能力展示明确占位反馈，不假报成功。
- [ ] **HOME-04**：375、390、768、1280、1440px 视口无非预期横向滚动、内容截断或浮层遮挡；移动软键盘与安全区下输入区保持可用。
- [ ] **HOME-05**：表单有标签、控件有可访问名称及清晰键盘焦点，浮层状态支持键盘与触控。
- [x] **HOME-06**：记录桌面/移动实际渲染截图、验收结果及与 Stitch 的差异；启动说明指向可运行首页。
