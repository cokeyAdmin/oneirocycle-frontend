# 本轮初始化需求

来源：用户 2026-11-13 明确规格。所有需求均仅限骨架与边界。

## Phase 1 — 前端基础工程

- [x] **ENG-01**：在现有前端独立仓库初始化，不覆盖 LICENSE 或修改后端。
- [x] **ENG-02**：安装兼容稳定依赖，提交锁文件；strict TypeScript、Next.js App Router、Tailwind 可构建。
- [x] **MOD-01**：建立账户、项目、资产、图像生成、视频生成、画布、3D、Agent 边界；不堆积空文件。
- [x] **LOAD-01**：画布及 3D 客户端按需加载；验证普通入口不加载引擎。
- [x] **STATE-01**：区分 Query 服务端缓存、Zustand 临时状态、可序列化项目文档；记录撤销/恢复/版本边界。
- [x] **CMD-01**：手动和 Agent 共用类型化创建节点、调整相机、提交任务命令；权限和幂等边界可测试。
- [x] **API-01**：统一客户端、结构化错误、认证接口；真实传输待 OpenAPI，不猜测 URL。
- [x] **JOB-01**：定义并核验任务查询、失败、取消、进度订阅、断线重查和终态停止规则；不伪造生成成功。
- [x] **CONTRACT-01**：交付前后端 OpenAPI 协商清单及契约接入步骤。
- [x] **QA-01**：环境变量示例、启动/格式化/lint/typecheck 配置；必要领域测试、production build、实际 HTTP 启动核验。
- [ ] **FLOW-01**：初始化任务关联 Linear，需求/计划/验收文档可追踪；无未授权推送、部署或页面实现。

## 后续能力（本轮不实现）

登录账户、项目 CRUD、资产上传管理、真实图像/视频生成、完整画布编辑、3D 场景交互、Agent 推理执行、产品页面与响应式视觉。

上述需求均映射 Phase 1。ENG 至 QA 的骨架验收已通过，证据见 docs/verification.md 和 01-REVIEW.md；FLOW-01 的本地任务关联与执行记录已完成，外部 Linear 进展/验收同步仍待 Hermes。
