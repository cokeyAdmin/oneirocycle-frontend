<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Visitor input to local React state | Prompt and search text are untrusted even though they remain in-browser. |
| Product-like controls to unavailable services | Creation, account, asset, and navigation controls could mislead users into believing a remote operation succeeded. |
| Browser to media/font origins | Stitch exports contain third-party hotlinks that would disclose requests and create availability dependencies if copied. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Spoofing | Creator and unavailable destination controls | high | mitigate | Keep actions local, centralize unavailable feedback, and expose no task ID, progress, saved/generated claim, fetch, or mutation path. |
| T-02-02 | Tampering | Prompt and search rendering | medium | mitigate | Use controlled values and React text rendering; do not use HTML injection APIs or source-export inline handlers. |
| T-02-03 | Information Disclosure | Inspiration media and fonts | medium | mitigate | Use local CSS/inline-SVG treatments and system fonts; do not ship Stitch/Google hotlinks. |
| T-02-04 | Denial of Service | VisualViewport listeners, marquee, and overlays | medium | mitigate | Remove listeners/cancel animation work on close/unmount, constrain scrolling, honor reduced motion, and restore focus. |
| T-02-SC | Tampering | npm installs | high | mitigate | No install task exists; any newly discovered package need must stop for the package-legitimacy gate before the lockfile changes. |
</threat_model>
