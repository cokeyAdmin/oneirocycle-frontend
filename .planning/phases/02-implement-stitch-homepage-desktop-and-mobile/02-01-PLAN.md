<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Visitor input to local React state | Prompt and search text are untrusted even though they remain in-browser. |
| Product-like controls to unavailable services | Creation, account, asset, and navigation controls could mislead users into believing a remote operation succeeded. |
| Browser to media/font origins | Stitch exports contain third-party hotlinks that would disclose requests and create availability dependencies if copied. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Spoofing | Primary creator and unavailable destination controls | high | mitigate | Keep all actions local, centralize the exact unavailable informational state, and expose no task ID, progress, saved/generated claim, fetch, or mutation path. |
| T-02-02 | Tampering | Prompt and inspiration search rendering | medium | mitigate | Use controlled values and React text rendering only; do not use HTML injection APIs or source-export inline event handlers. |
| T-02-03 | Information Disclosure | Inspiration media and fonts | medium | mitigate | Use committed/local CSS or inline-SVG illustrative treatments and the existing system font stacks; do not ship Stitch/Google hotlinks. |
| T-02-04 | Denial of Service | Marquee, overlays, and fixed mobile layers | low | mitigate | Honor reduced motion, pause marquee on hover/focus, constrain local scrolling, and remove listeners/restore focus when overlays close. |
| T-02-SC | Tampering | npm installs | high | mitigate | No install task exists; if execution discovers a package is necessary, stop and require the package-legitimacy gate before changing the lockfile. |
</threat_model>
